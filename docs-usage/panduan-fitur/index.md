# Panduan Fitur

Berikut daftar seluruh fitur yang tersedia di **CVI Manager**, dikelompokkan
berdasarkan peran pengguna.

---

## Fitur untuk Admin

| Fitur | Deskripsi | Panduan |
|---|---|---|
| Mengelola Instrumen | Membuat & mengelola instrumen, item, dimensi, dan penugasan expert | [Lihat panduan](instrumen.md) |
| Hasil CVI | Menghitung I-CVI per item, S-CVI, dan mengekspor ke Excel | [Lihat panduan](hasil-cvi.md) |
| Mengelola Pengguna | Mengubah data pengguna dan menonaktifkan akun | [Lihat panduan](pengguna.md) |
| Bidang Keahlian | Mengelola daftar master bidang keahlian | [Lihat panduan](bidang-keahlian.md) |
| Log Aktivitas | Melihat riwayat aktivitas seluruh pengguna | [Lihat panduan](log-aktivitas.md) |

---

## Fitur untuk Expert

| Fitur | Deskripsi | Panduan |
|---|---|---|
| Penilaian Saya | Menilai relevansi item instrumen yang ditugaskan | [Lihat panduan](penilaian-saya.md) |

---

## Fitur untuk Semua Peran

| Fitur | Deskripsi | Panduan |
|---|---|---|
| Profil Saya | Memperbarui identitas pribadi dan bidang keahlian | [Lihat panduan](profil-saya.md) |

---

!!! info "Fitur berdasarkan peran"
    Menu yang Anda lihat di sidebar tergantung peran akun Anda. Admin melihat menu
    pengelolaan; expert hanya melihat **Penilaian Saya** dan **Profil Saya**. Jika
    sebuah menu tidak muncul padahal seharusnya tersedia untuk Anda, hubungi administrator.
