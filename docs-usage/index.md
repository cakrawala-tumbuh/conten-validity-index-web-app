# CVI Manager

Selamat datang di panduan pengguna **CVI Manager** — aplikasi pengelolaan
**Content Validity Index (CVI)** untuk instrumen penelitian.

CVI adalah metode statistik untuk mengukur **validitas isi** sebuah instrumen
(kuesioner, tes, atau angket). Caranya: setiap item instrumen dinilai relevansinya
oleh sejumlah ahli (expert), lalu sistem menghitung rasio persetujuan antar-ahli.
CVI Manager mengelola seluruh alur ini — dari menyusun instrumen, menugaskan
expert, mengumpulkan penilaian, sampai menghitung dan mengekspor hasilnya.

---

## Untuk Siapa Aplikasi Ini?

Aplikasi memiliki dua peran pengguna dengan tampilan yang berbeda:

- **Admin** — menyusun instrumen, mengelola item & dimensi, menugaskan expert,
  serta menghitung hasil CVI.
- **Expert (Penilai)** — memberi skor relevansi pada item instrumen yang
  ditugaskan kepadanya.

---

## Fitur Utama

- **Mengelola Instrumen** — buat instrumen beserta item, dimensi, dan kisi-kisi konstruk.
- **Hasil CVI** — hitung I-CVI per item, S-CVI/Ave, S-CVI/UA, lalu ekspor ke Excel.
- **Penilaian Saya** — expert menilai setiap item dengan skala 1–4 disertai catatan.
- **Mengelola Pengguna** — kelola data pengguna dan bidang keahliannya.
- **Bidang Keahlian** — daftar master bidang keahlian yang dapat dipilih expert.
- **Log Aktivitas** — riwayat seluruh aktivitas pengguna di sistem.
